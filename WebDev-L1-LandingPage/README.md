# NovaEdge — Digital Solutions Landing Page

## Project Overview
This project was created as part of the OIBSIP Web Development Level 1 Task 1 internship assignment. It is a highly professional, modern, and responsive landing page for a fictional technology company named "NovaEdge".

## Objective
The goal is to build a visually impressive, company-quality landing page using only HTML and CSS, without relying on JavaScript or CSS frameworks. The design emphasizes a professional aesthetic, clean layout, strong visual hierarchy, and full responsiveness across devices.

## Technologies Used
- HTML5
- CSS3

## Features
- **Sticky Navigation Bar:** Remains visible while scrolling and utilizes semantic anchor links. CSS-based hamburger menu for mobile.
- **Hero Section:** Strong initial visual impact with gradients, CSS shapes, and clear Call to Action (CTA) buttons.
- **Trust / Stats Strip:** Professional statistics highlighting company expertise.
- **Solutions Section:** Service cards featuring custom CSS visuals and smooth hover effects.
- **Why Choose Us Section:** Split layout presenting company advantages and a custom CSS dashboard mockup.
- **About Section:** Clean, readable company description with its own CTA.
- **Work Process Section:** Step-by-step process visualization.
- **Testimonials Section:** Professional client feedback cards with custom avatars.
- **Call to Action Section:** A concluding section to drive user conversion.
- **Footer:** Comprehensive footer with branding, navigation, contact details, and social placeholders.

## Sections
- **Home (Hero):** Introduction to NovaEdge with an abstract CSS-based glassmorphism visual.
- **Stats:** Brief numerical highlights of the company's achievements.
- **Solutions:** Grid of services offered (Web Development, UI/UX, Cloud, Digital Strategy).
- **Why Us:** Distinct advantages of choosing NovaEdge with a CSS dashboard visual element.
- **About:** Deep dive into the company's purpose and mission.
- **Work Process:** Four-step approach (Discover, Plan, Build, Launch).
- **Testimonials:** Fictional client reviews showcasing credibility.
- **Final CTA:** Encouraging the visitor to start a conversation.
- **Footer:** Closing navigation and contact info.

## Responsive Design
The website uses CSS Flexbox and Grid to be fully optimized for desktop, laptop, tablet, and mobile viewing.
- Breakpoints handle layout restructuring at 1024px, 768px, and 480px.
- Navigation elegantly collapses into a CSS-only hamburger menu on smaller screens.
- Multi-column grids gracefully degrade into single-column layouts on mobile devices.

## How to Run
1. Navigate to the project folder (`WebDev-L1-LandingPage`).
2. Open `index.html` directly in any modern web browser (e.g., Chrome, Edge, Firefox, Safari) by double-clicking it.
3. No server or build process is required since the project consists entirely of vanilla HTML and CSS.
