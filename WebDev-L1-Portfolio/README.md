# Prathiksha H Kotian — Personal Portfolio

## Project Overview
A highly professional, modern, recruiter-focused personal portfolio website. It presents technical skills, projects, educational background, and contact information in a clean, impressive, and interactive layout.

## Objective
This project was developed for the **OIBSIP Web Development Level 1 - Task 2**. The goal was to design and implement a polished personal portfolio from scratch without relying on large frameworks, focusing on core web technologies and modern design principles.

## About
The portfolio features a custom, elegant design tailored for an Information Science & Engineering student. It emphasizes a strong visual hierarchy, excellent whitespace, sophisticated typography, and smooth CSS-based animations to convey professionalism and career readiness.

## Technologies Used
- **HTML5:** Semantic structure and accessibility.
- **CSS3:** Custom properties (variables), Flexbox/Grid layouts, responsive media queries, and smooth transitions.
- **JavaScript (Vanilla):** Sticky navigation, mobile menu toggle, smooth scroll active state management, and front-end form validation.
- **Google Fonts:** Inter font family for clean typography.

## Features
- **Modern UI/UX:** Clean, premium design with a deep navy and electric blue color palette.
- **Fully Responsive:** Adapts seamlessly across desktop (1440px), laptop (1280px), tablet (1024px/768px), and mobile (430px/390px/375px).
- **Interactive Navigation:** Sticky header with smooth scrolling links and an animated mobile hamburger menu.
- **Dynamic Profile Visual:** Animated gradient profile placeholder highlighting creativity.
- **Form Validation:** Front-end validation for the contact form with simulated submission states.

## Sections
- **Hero:** Introduction with professional titles, a brief description, call-to-action buttons, and social links.
- **About:** A 3-paragraph summary of background and interests, featuring professional highlight cards.
- **Skills:** A comprehensive, grid-based display of technical skills categorized into Programming, Web, Databases, Tools, and Additional Areas.
- **Projects:** Featured project cards (e.g., NovaEdge Landing Page, Temperature Converter) including descriptions, technology tags, and view/GitHub links.
- **Education & Learning Journey:** A timeline showcasing the B.E. in Information Science & Engineering, alongside a block detailing the ongoing learning journey and professional qualities.
- **Contact:** A front-end contact form and direct contact methods (email, LinkedIn, GitHub).

## Responsive Design
The layout uses a mobile-first approach where appropriate, combined with desktop-first max-width media queries. It has been thoroughly tested across:
- 1440px Desktop
- 1024px & 768px Tablets
- 430px, 390px, & 375px Mobile devices

## How to Run
1. Clone or download the repository to your local machine.
2. Open the `WebDev-L1-Portfolio` folder.
3. Double-click `index.html` to open it in your default web browser, or use a local server like VS Code's "Live Server" extension for the best experience.
